# NEXORA — The City Mall (Futuristic Luxury 3D Shopping Mall Web Experience)

A state-of-the-art, hyper-luxurious 3D shopping mall web application built using **React, Vite, Tailwind CSS, Framer Motion, and Lucide Icons**.

## 🌟 Key Features

- **Hero Visual & Floating Spatial Badges**: Full-screen architectural background with interactive floating spatial zone badges (`FASHION`, `DINING`, `LIFESTYLE`, `ENTERTAINMENT`) and real-time hover image preview cards.
- **Section 01 — Discover the Mall**: Perfectly aligned horizontal category deck (`01 FASHION`, `02 DINING`, `03 ENTERTAINMENT`, `04 WELLNESS`, `05 LIFESTYLE`) with progress line indicator.
- **Section 02 — Explore Stores & 2D Vector Blueprint Map**: Interactive directory map system with level selector tabs (`L3`, `L2`, `L1`), store category pills, and floating store detail HUD card.
- **Section 03 — Explore Every Level**: Architectural level spotlight gallery with level preview cards and detailed tier descriptions.
- **Section 04 — Featured Experiences**: Asymmetric luxury panels for `SHOP`, `DINE`, `PLAY`, and `UNWIND` with hover micro-animations.
- **Section 05 — Brand Showcase**: Minimal monochrome brand logo row (`ZARA`, `H&M`, `NIKE`, `SEPHORA`, `ADIDAS`, `MICHAEL KORS`, `PUMA`, `UNIQLO`).
- **Section 06 — Dining Experience**: Culinary restaurant showcase cards integrated with table reservation booking modal.
- **Section 07 — Events & Galas**: Cultural calendar poster cards with digital RSVP pass registration modal.
- **Section 08 — Smart Visitor Tools**: Interactive utility grid for live parking metrics, store finder, mall map, opening hours, and EV chargers.
- **Section 09 — Location & Digital Map**: Stylized dark-mode vector map with location pin, transport details (`BY CAR`, `BY METRO`, `BY BUS`), and Google Maps routing.
- **Section 10 — Dramatic Final CTA**: Highway motion blur background with electric blue action CTA.

## 🛠️ Technology Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Celebration Effects**: Canvas Confetti

## 🚀 Getting Started
